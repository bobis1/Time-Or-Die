# Time until die

![project banner](/Assets/banner.png)

This is a godot game about going through different eras of time to retrieve your family heirlooms.

## Controls
W-A-D/Up-Left-Right arrows: Movement
Z: Open Time Travel menu
Space: Jump

## Roadmap
During Horizons Arcana, we only made for the game base, since there's only a limited amount of time, we don't really have enough time for making the story and any interactive elements.
